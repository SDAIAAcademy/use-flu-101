# الحد الأدنى للإلمام بالبيانات والذكاء الاصطناعي لجميع العاملين: المختبرات

ستة مختبرات لمقرر أكاديمية سدايا **USE-FLU-101**، مجموعها 75 دقيقة. كل مختبر صفحة واحدة بالعربية تُقرأ على الهاتف: الهدف، والمواد، وخطوات بدقائقها، ومفتاح مطوي يطابق المشارك عمله به، وأسئلة تحقق، وتمرين إضافي ✱، وملاحظات للمدرّب. لا رموز برمجية يكتبها المشارك.

كل المختبرات في جهة واحدة: **شركة طيف للمطارات**، شركة افتراضية تشغّل ثلاثة مطارات إقليمية. كل الأسماء والأرقام والجهات والعناوين البريدية وهمية.

## ما يحتاجه المشارك

- متصفح على هاتف أو حاسوب.
- للمختبر 3.1 فقط: المساعد المعتمد في جهته داخل بيئة تشغيل معزولة لا تحوي إلا مواد اصطناعية. من لا مساعد لديه يكمل المختبر على الردّين المكتوبين في الصفحة. لا يُنزَّل أي نموذج على جهاز المشارك.

## نقطة البداية والحل

كل مختبر يبدأ من مواد جاهزة معروضة في صفحته ومحفوظة في `files/`، ولا يعتمد على مختبر آخر. المختبر 6.1 يستخدم ردًّا من المختبر 5.1 بعد تصحيحه، وهو معروض كاملًا في صفحته.

| المختبر | الصفحة | يبدأ من | الحل المرجعي |
|---|---|---|---|
| 1.1 | `M1_1_vignettes.html` | `files/vignettes.txt` | `solutions/key.json`، القسم 1.1 |
| 2.1 | `M2_1_sanitise.html` | `files/work_items/` (خمسة عناصر) | `solutions/sanitised/` (خمس نسخ منقّاة)، والقسم 2.1 |
| 3.1 | `M3_1_request.html` | `files/meeting_notes.txt` | `solutions/standin.json` (الطلب المرجعي والردّان)، والقسم 3.1 |
| 4.1 | `M4_1_dashboard.html` | `files/dashboard.html`، `files/ai_summary.txt`، `files/dashboard_data.csv` | القسم 4.1 |
| 5.1 | `M5_1_drafts.html` | `files/drafts.txt` | القسم 5.1 |
| 6.1 | `M6_1_disclosure.html` | `files/finished_output.txt` | القسم 6.1 |

`solutions/answer_key.md` يشرح للمدرّب كل ما زُرع في المواد وأين يُكتشف.

## تشغيل الحلول

```bash
uv run labs/solutions/check.py          # كل المختبرات
uv run labs/solutions/check.py 2.1 4.1  # بعضها
```

ملف واحد لا اعتماديات له، ويحتاج [uv](https://docs.astral.sh/uv/). يطبع لكل مختبر ما أعاد حسابه ثم `PASS`، ولا يكتب شيئًا على القرص ولا يتصل بأي نموذج.

**ما يُشغَّل فعلًا:** مطابقة مفتاح الفرز بصفحة المختبر، ووجود كل تفصيل مؤشَّر عليه في الأصل وغيابه عن النسخة المنقّاة، وإعادة حساب أرقام اللوحة من ملف البيانات ومن البيانات المضمّنة في صفحة اللوحة، ومطابقة كل مسودة بمصدرها، وعنصرا سطر الإفصاح.

**ما يُشغَّل بنموذج بديل:** خطوة المساعد في المختبر 3.1. النموذج البديل (`solutions/standin.json`) ردّان مكتوبان سلفًا، في أولهما الأخطاء التي يقع فيها مساعد حقيقي أمام طلب عام. لم يُشغَّل هذا المختبر على نموذج حقيقي: جرّبه المدرّب في المساعد المعتمد لديه قبل كل دفعة.

## إعادة توليد المواد

```bash
uv run labs/_tools/prepare_files.py
```

يكتب ملفات `files/` والمفتاح من جديد ببذرة ثابتة، فتخرج البايتات نفسها في كل مرة، ويحدّث النصوص المعروضة في صفحات المختبرات لتطابق الملفات.
